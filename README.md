# CineArm 下载

CineArm 用于机械臂拍摄的项目编辑、时间线和节点编排。

CineArm 为闭源软件。本仓库仅提供安装包和版本说明，不公开源代码。

**[进入版本下载页](https://github.com/Kikuku10/CineArm-Releases/releases)**

## 选择安装包

- **Mac（Apple Silicon）**：下载 `CineArm-macOS-AppleSilicon-版本号.zip`，解压后将 `CineArm.app` 放入“应用程序”。
- **Windows x64**：下载 `CineArm-Windows-版本号-x64-setup.exe`，运行安装程序。

首次打开如有系统安全提示，请按系统界面确认。需要校验文件完整性时，请使用版本页面中的 `SHA256SUMS.txt`。

## 免费版与 Studio

- **免费版**：无需登录，可编辑、预览、保存和导出项目，也可连接机械臂、使能、手动控制、拖拽示教和使用跟焦；实体项目执行最多 1 条时间线，每条时间线最多 4 个姿态关键帧或节点。
- **Studio**：解除上述时间线和姿态关键帧数量限制；设备兼容与安全限制保持不变。
- **激活方式**：在“偏好设置 → 账号”登录已开通 Studio 的账户并激活本机，激活不会自动连接或启动设备。
- **设备数量**：Studio 永久许可最多绑定 2 台设备，Mac、Windows、iPad 每台均占 1 个名额；第三台激活时会自动替换首次激活时间最早的一台。
- **离线与换机**：成功联网验证后最多可离线使用 7 天。退出登录不会释放云端设备名额；在“设备管理”中反激活设备才会释放名额。
